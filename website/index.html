pyPolar

Multi-Objective Bayesian Optimization for Human-in-the-Loop Robotics

Neil Janwani, Author Two, Author Three
Dynamic Mobility Lab, Georgia Tech
In Review
arXiv Code Documentation

Abstract

Personalizing assistive and wearable robots to an individual user requires balancing several competing objectives, such as metabolic cost, walking speed, and subjective comfort, each of which is expensive and noisy to measure on a human. We present pyPolar, an open-source library for multi-objective Bayesian optimization in human-in-the-loop settings. pyPolar models each objective with an independent Gaussian process over a shared action space, allowing objectives to be measured on decoupled schedules and at different rates. Built entirely on BoTorch, it provides principled noise modeling, leave-one-out diagnostics, and Pareto-front estimation from sparse human data. We evaluate pyPolar on synthetic benchmarks and on pilot data from human subjects, and show that it recovers accurate trade-off fronts from few measurements. pyPolar is designed to make multi-objective personalization reproducible and accessible to the robotics community.
